CHAPTER 02 · 배경

왜 SAVE trial 은 null 이었나 — 평균의 함정

OSA 는 심혈관 위험 인자로 확립됐지만 CPAP RCT 결과는 평균적으로 null 이었습니다

OSA–심혈관 연결
상기도 반복 폐쇄 → 간헐적 저산소·교감신경 항진·내피기능 장애·혈압 변동 → 관상동맥·뇌혈관·심방세동 위험 증가.
SAVE trial (2016)
AHI ≥12 + 관상동맥·뇌혈관 질환. CPAP + 통상 치료 vs 통상 치료. 1차 결과는 복합 심혈관 사건.
재분석의 질문
평균 null 은 정말 ‘효과 없음’인가, 이득과 손해가 섞여 가려진 것인가.

CHAPTER 05 · 결과 ②

무호흡 중증도·졸음으로는 이득군이 갈리지 않았다

원문이 스스로 짚은 점 — AHI 하나로 CPAP 반응을 예측하는 데는 한계가 있습니다

AHI 단독으로는 못 가름
AHI 3분위로 나눈 비교에서는 CPAP 효과 차이가 드러나지 않았습니다. 기계학습 모델이 필요했던 이유입니다.
이득 예측군은 무호흡이 덜 심했다
AHI·ODI 가 낮고 산소포화도가 약간 높았으며, 삶의 질 점수가 낮았습니다 — 중증도보다 수면 분절·증상 부담 쪽 해석.
졸음 점수는 차이 없음
Epworth 졸음 척도(ESS)는 세 군 사이 차이가 없었습니다.
관상동맥 과거력은 손해 쪽
심근경색·관상동맥 재개통 과거력이 많은 군이 손해 예측군이었습니다. 뇌졸중 과거력은 이득 쪽 경향(유의 경계).

CHAPTER 07 · 두 갈래

이득 예측군과 손해 예측군 — 어떤 환자였나

원문 표 1–3 의 기저 특징 비교입니다 — 특징 기술이지 의뢰 기준이 아닙니다

이득 예측군
무호흡은 덜 심하고, 삶의 질은 낮았습니다
  • AHI·ODI 낮음 · 산소포화도 약간 높음
  • SF-36 신체·정신 건강 점수 낮음
  • 심박변이도 높음 — 자율신경 반응성 해석
  • 뇌졸중 과거력 쪽 이득 경향(유의 경계)
손해 예측군
관상동맥 과거력이 많았습니다
  • 심근경색·관상동맥 재개통 과거력 많음
  • 고혈압 약 사용 많음
  • 무호흡 지표 더 심함 · 산소화 약간 나쁨
  • 기저 삶의 질 점수는 더 좋음
Tip · 손해 예측이 ‘CPAP 금지’는 아닙니다 — 증상이 있으면 증상 치료 적응은 그대로입니다.근거 · Communications Medicine 2026.04 · 표 1–3 · 고찰
