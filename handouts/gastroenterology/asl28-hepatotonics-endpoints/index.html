간장약 처방 설명표: 간효소·간지방·섬유화·허가·급여

간효소 감소, 간지방 변화, 조직학적 섬유화와 장기 임상결과를 서로 다른 평가 지표로 설명한다.

핵심 판단 한눈에

연자 Q&A 56–57쪽 · 간장약별 설명

약제연자의 설명
라이넥주허가 문구의 핵심은 만성 간질환에서 간기능 개선. 정상 LFT의 지방간에는 허가 취지에 맞는 사용으로 보기 어렵다고 답변
히시파겐씨주만성 간질환의 간기능 개선. 연자는 급여도 AST/ALT 상승을 전제로 한다고 설명
두 주사제의 평가연자는 사용하지 않는다고 답변. ALT 감소 외 조직학적 개선·hard outcome 임상시험을 제시하지 않았고, 태반추출물은 소규모 연구 수준이라고 설명
UDCA·silymarin (Legalon)hard outcome 개선의 대규모 임상시험 근거와 지침 권고를 구분. 현실적인 처방 경험으로 소개
DDB 포함 제제ALT 감소로 감별진단에 혼란을 줄 수 있어, 연자는 초기 조합으로 UDCA + silymarin을 많이 사용한다고 답변

처방 전 설명·기록

  • 현재 AST/ALT와 초음파 간지방 소견을 각각 기록한다.
  • 처방 목적이 간효소 개선인지, MASH·섬유화 치료인지 분리해 설명한다.
  • 허가 문구와 급여 조건을 질환 개선 효과와 같은 뜻으로 쓰지 않는다.

연자 Q&A의 핵심

“수치가 좋아짐”을 “섬유화가 좋아짐”으로 바꾸지 않는다

정상 LFT의 지방간 환자에게 간기능 개선 주사제를 투여하는 질문과, UDCA·silymarin 처방 경험에 대한 답변을 나누어 적용한다.
